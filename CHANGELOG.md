# CHANGELOG

All notable changes to PixelMap will be documented in this file.

## [1.0.0] - 2024-XX-XX

### Added
- Initial release
- Pixelated map tiles with OpenStreetMap data
- Fog of war exploration system
- 5 Minecraft-style zoom levels (0-4)
- Real-time compass heading indicator
- GPS tracking and location history
- Supabase backend for cloud sync
- User authentication and profiles
- Settings management
- Exploration statistics and achievements
- n8n agent workflows for tile processing
- Background location tracking

### Features
- Cross-platform support (iOS/Android)
- Offline mode support
- PostGIS geospatial queries
- Batch track processing
- Tile caching system
